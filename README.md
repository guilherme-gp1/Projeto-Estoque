## 📖 Sobre o Projeto

O **Fallen Realms Mobile** é um aplicativo desenvolvido como extensão da plataforma web Fallen Realms, com o objetivo de permitir que os usuários gerenciem seus personagens de maneira prática e acessível por dispositivos móveis.

Diferentemente da plataforma Web, o aplicativo Mobile não possui funcionalidades de gameplay, exploração ou combate. Sua proposta é oferecer uma interface simplificada para o gerenciamento dos personagens cadastrados pelo usuário.

Por meio do aplicativo, será possível criar novos personagens, visualizar suas informações e editar seus dados sempre que necessário.

## 🎯 Objetivo do Aplicativo

Facilitar o gerenciamento dos personagens do Fallen Realms, permitindo que os jogadores tenham acesso às informações de seus personagens diretamente pelo celular.

## 📱 Funcionalidades

- [ ] Cadastro e autenticação de usuários.
- [ ] Visualização dos personagens cadastrados.
- [ ] Criação de novos personagens.
- [ ] Edição das informações dos personagens.
- [ ] Visualização dos atributos e status.
- [ ] Consulta de raça e classe dos personagens.
- [ ] Integração com a plataforma Web por meio de API.

## 🛠️ Tecnologias Utilizadas

As tecnologias utilizadas no desenvolvimento do aplicativo incluem:

- **TypeScript:** tipagem estática e desenvolvimento.
- **[Framework Mobile]:** desenvolvimento da aplicação móvel.
- **[Biblioteca de interface]:** construção dos componentes visuais.
- **API REST:** comunicação com o backend do Fallen Realms.
- **Git e GitHub:** versionamento e gerenciamento do código-fonte.

## 🔗 Integração com Fallen Realms Web

O aplicativo Mobile foi idealizado para trabalhar em conjunto com a plataforma Web do Fallen Realms.

A comunicação entre as aplicações permite compartilhar informações dos usuários e seus personagens, mantendo os dados centralizados no backend.

**Fallen Realms Web:**
- Plataforma principal do projeto.
- Gerenciamento e desenvolvimento das funcionalidades do RPG.
- Experiência de jogo e sistemas de gameplay.

**Fallen Realms Mobile:**
- Criação de personagens.
- Visualização de personagens.
- Edição de personagens.
- Gerenciamento das informações dos personagens.

## 💻 Como executar o projeto

### Pré-requisitos

- Node.js
- NPM
- Ambiente de desenvolvimento mobile compatível com o framework utilizado.

### 1. Clonar o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Entrar na pasta do projeto

```bash
cd Mobile-Projeto
```

### 3. Instalar as dependências

```bash
npm install
```

### 4. Executar o aplicativo

*O comando de execução depende do framework mobile utilizado.*
